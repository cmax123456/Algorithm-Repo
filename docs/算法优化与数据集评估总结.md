# AsterTrack 多相机刚体跟踪：算法优化与数据集评估总结

**统计截至：2026-09-02**  
**适用对象：** 20 相机、长距离、侧向（side_optv1）、5.5cm Marker 的 `helmet_01` 六点刚体跟踪场景。

---

## 1. 结论摘要

当前推荐的稳定版本采用 **自适应 HSV 检测 + 极线约束三角化 + 自适应多视图共识 + 几何质量评分 + 加权 Kabsch + 时序跟踪**。

在 4 组无粗大位姿错误的 5.5cm 长距离数据集上，该版本均达到：

- **300/300 帧跟踪成功，0 丢帧；**
- 位姿位置误差均值：**0.3634 ~ 0.4519 cm**；
- 位姿角度误差均值：**1.7517 ~ 2.5227°**；
- 稳定数据集的平均位置误差：**0.3980 cm**；
- 稳定数据集的平均角度误差：**1.9777°**。

综合位置精度最佳的数据集为 `normalopt_t2p5_dynamic_0001`，位置误差均值为 **0.3634 cm**；综合角度精度最佳的数据集为 `normalopt_t2p5_h04t3p5_dynamic_0001`，角度误差均值为 **1.7517°**。两者的整体精度处于相同水平。

> 注意：`100% 跟踪率`表示每帧都有返回位姿，不等价于每帧的身份匹配均正确。`h04t1p5` 数据集已发现连续 20 帧近 180° 的对称性误匹配，因此不应把其全量均值作为可靠精度指标。

## 2. 当前推荐算法与运行配置

### 2.1 默认运行配置

```bash
DETECTIONS_SOURCE=detected_2d_frames_quality.json \
USE_EPIPOLAR=1 \
MIN_VIEWS=auto \
python3 marker_tracking_pipeline.py
```

### 2.2 推荐实现文件

当前已验证实现位于各已评估数据集目录内，核心文件为：

- `video_marker_detector.py`：从 20 路 MP4 视频检测匿名 2D Marker blob；
- `marker_tracking_pipeline.py`：三角化、刚体匹配、位姿估计、时序跟踪和 GT 评估；
- `detected_2d_frames_quality.json`：包含检测坐标与质量元数据的检测输出；
- `tracking_report_geometryquality.log`：完整逐帧跟踪及 GT 误差报告。

### 2.3 在线候选点质量模型

当前在线排序和位姿拟合保持使用已验证的**几何质量**，而不是直接依赖外观置信度：

\[
quality = 0.5 \times view\_score + 0.5 \times residual\_score
\]

其中：

- `view_score`：参与三角化的相机数量越多，候选质量越高；
- `residual_score`：多射线精化残差越小，候选质量越高。

该策略能够在保留稀疏帧有效候选的同时，降低高密度场景中幽灵交会点对刚体匹配的干扰。

## 3. 已完成的关键优化

| 环节 | 优化内容 | 目的与效果 |
|---|---|---|
| 2D 检测 | 自适应 HSV 阈值 | 根据每帧红色像素的饱和度、亮度分布调整阈值，改善远距离、小 blob 和运动模糊条件下的召回。 |
| 2D 检测 | blob 质量元数据 | 输出面积、圆度、平均饱和度、平均亮度及 `detection_confidence`，为离线诊断和后续数据驱动标定保留特征。 |
| 三角化 | 极线约束 | 通过标定相机内外参计算基础矩阵，在射线求交前滤除几何上不可能的跨相机 blob 对。 |
| 三角化 | 多射线精化与残差 | 对候选点进行多视图射线精化，用多射线残差衡量几何可信度。 |
| 三角化 | 自适应多视图共识 | 当有效相机数不少于 10 且 blob 数不少于 38 时，自动要求至少 3 个相机支持；其他稀疏帧保留 2 视图候选。 |
| 姿态估计 | 几何质量加权 Kabsch | 在保留全部几何有效对应点的前提下，降低低视图数或高残差候选对刚体拟合的影响。 |
| 时序跟踪 | 质量感知关联 | 将预测位置距离与候选几何质量联合用于关联，降低跟踪漂移到邻近幽灵点的概率。 |
| 稳定性 | 定期全局重验证 | 周期性或 RMSE 异常时重新执行全局匹配，用于纠正普通时序漂移。 |

## 4. 已验证的最佳结果

### 4.1 可靠全量数据集结果

下表中的 4 组数据均无位置误差大于 3cm 或角度误差大于 15° 的粗大位姿错误，可作为当前算法的可靠全量评估结果。

| 数据集 | 跟踪率 | 丢帧 | 匹配 Marker/帧 | Fit RMSE Mean (cm) | 位置误差 Mean / P95 (cm) | 角度误差 Mean / P95 (°) | Marker 误差 Mean (cm) |
|---|---:|---:|---:|---:|---:|---:|---:|
| `marker55_dynamic_0003` | 300/300（100%） | 0 | 5.83 | 0.5832 | 0.4059 / 0.8518 | 1.8779 / 4.1213 | 0.4404 |
| `marker55_normaloptv1_dynamic_0001` | 300/300（100%） | 0 | **5.88** | 0.7974 | 0.4519 / 0.8150 | 2.5227 / 4.8224 | 0.6223 |
| `marker55_normalopt_t2p5_dynamic_0001` | 300/300（100%） | 0 | 5.83 | 0.5585 | **0.3634 / 0.6544** | 1.7584 / 3.7455 | **0.4123** |
| `marker55_normalopt_t2p5_h04t3p5_dynamic_0001` | 300/300（100%） | 0 | 5.81 | **0.5508** | 0.3708 / 0.7530 | **1.7517 / 3.5999** | 0.4141 |

### 4.2 最优结果说明

1. **最佳综合位置精度：** `marker55_normalopt_t2p5_dynamic_0001`
   - 位置误差均值 **0.3634 cm**；
   - P95 位置误差 **0.6544 cm**；
   - Marker 平均位置误差 **0.4123 cm**。

2. **最佳角度精度与拟合 RMSE：** `marker55_normalopt_t2p5_h04t3p5_dynamic_0001`
   - 角度误差均值 **1.7517°**；
   - P95 角度误差 **3.5999°**；
   - Fit RMSE 均值 **0.5508 cm**。

3. **`t2p5` 相对 `normaloptv1` 的改善：**
   - 位置误差均值从 0.4519cm 降至 0.3634cm，降低 **19.6%**；
   - 角度误差均值从 2.5227° 降至 1.7584°，降低 **30.3%**；
   - Marker 平均位置误差从 0.6223cm 降至 0.4123cm，降低 **33.7%**。

## 5. 异常数据集与边界条件

### `marker55_normalopt_t2p5_h04t1p5_dynamic_0001`

该数据集的检测覆盖与 `h04t3p5` 基本一致，但当前算法发生了一段近对称刚体解翻转。

| 指标 | 全量 300 帧 | 剔除异常第 80~99 帧后的 280 帧 |
|---|---:|---:|
| 跟踪率 | 300/300（100%） | 280/280（100%） |
| 粗大错误帧数 | 20 | 0 |
| 位置误差 Mean / Median (cm) | 1.1724 / 0.3489 | 0.3711 / 0.3354 |
| 角度误差 Mean / Median (°) | 13.6441 / 1.7325 | 1.7923 / 1.6070 |
| Marker 误差 Mean (cm) | 1.3571 | 0.4113 |

**异常特征：**

- 异常帧范围为第 **80~99 帧**；
- 位置误差约 12.14~12.55cm；
- 角度误差约 178.42~179.97°；
- 第 80 帧的重验证选择了一个近对称但错误的刚体对应关系，随后时序跟踪将错误位姿持续传播；
- 异常帧的局部 Fit RMSE 仍较低、匹配点数仍为 4~6 个，说明现有局部几何评分不足以消除该类对称性歧义。

**结论：** 该数据集说明当前版本已具备高召回和连续输出能力，但对近 180° 的全局身份排列翻转仍需额外保护；全量指标不纳入可靠精度均值。

## 6. 已验证但未作为默认策略的方案

| 方案 | 验证结论 | 当前处理 |
|---|---|---|
| 跨相机重投影误差硬过滤 | 会误删远距离、模糊或亚像素偏差下的真实候选点，造成候选覆盖不足与丢帧。 | 不作为在线硬阈值；仅记录诊断字段。 |
| blob 外观置信度直接参与 Kabsch 权重 | 面积、圆度、HSV 外观分数与实际 3D 定位精度相关性不足，跨 marker 尺寸和布局时会导致位置精度退化。 | 不作为在线权重；保留元数据用于离线标定。 |
| 仅以 2 视图构造候选点 | 高相机覆盖、blob 密集场景下易产生幽灵交会点。 | 使用 `MIN_VIEWS=auto`，在高密度帧自动提升为 3 视图共识。 |

## 7. 后续优化优先级

### P0：解决对称性/近对称性位姿翻转

1. **重验证替换门控：** 全局候选替换当前时序解前，要求其重投影、匹配数量和加权拟合误差有明确优势，而非仅“相等或更好”。
2. **旋转连续性代价：** 对无物理运动依据的接近 180° 旋转跳变施加强惩罚，避免单帧替换为镜像或近对称排列。
3. **短时窗确认：** 对重验证候选在相邻若干帧内进行累计评分；只有持续优于时序解时再切换。
4. **身份排列消歧：** 结合上一帧位姿投影的 marker-to-blob 对应关系，增加显式身份连续性约束。

### P1：数据驱动质量标定

1. 将 blob 面积、圆度、HSV 统计量、候选多视图数量、射线残差、平均/最大重投影误差与 GT 3D 误差按候选点关联；
2. 分别统计 4cm/5.5cm、side/staggered 布局中的相关性；
3. 基于实测相关性训练分段质量函数、逻辑回归或轻量模型；
4. 仅在低置信度且低多视图支持同时出现时做温和降权，不使用硬剔除。

## 8. 复现与结果文件

每个已评估数据集目录中保留以下产物：

- `detected_2d_frames_quality.json`：统一检测结果与质量特征；
- `detection_report_quality.log`：20 路视频检测统计；
- `tracking_report_geometryquality.log`：最终配置下的完整跟踪和 GT 误差报告；
- `video_marker_detector.py`、`marker_tracking_pipeline.py`：所使用的算法实现。

建议后续评测始终使用第 2 节所列固定配置，并将“跟踪率、粗大位姿错误帧数、位置/角度误差 P95”作为同时必报的稳定性指标。
